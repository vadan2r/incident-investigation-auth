## Description

This file contains 12 synthetic Linux authentication and administrative activity records designed to represent a fictional security incident involving SSH authentication attempts, a successful login, and privileged command execution.

The records include events generated by OpenSSH, PAM, and sudo message formats.

## Preliminary Observations

- Multiple failed authentication messages associated with account `j.smith`.
- An invalid user attempt involving account `admin2`.
- A successful authentication for `j.smith` from a different source IP.
- A privileged command invocation involving `/etc/shadow`.
- Subsequent closure of privileged and SSH sessions.

## Evidence Limitations

- The dataset is synthetic and does not originate from a production server.
- The timestamps use a normalized ISO 8601 format.
- No independent network, endpoint, or identity-provider evidence is available.
- The command log does not establish whether file contents were successfully obtained.
- The dataset does not identify the human operator behind the account activity.
- The SHA-256 hash verifies the current file content but does not establish its original authenticity or collection history.

**Initial Assessment:** The dataset contains a suspicious authentication pattern that warrants further examination. Unauthorized access has not been confirmed.
